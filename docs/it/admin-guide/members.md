# Registro Soci

Ogni richiesta di adesione firmata e confermata diventa una voce del
**libro soci**, in **Admin → Registro soci → Soci**.

![L'elenco dei soci](../assets/screenshots/admin-members-list.png)

## Trovare un Socio

L'elenco è ordinabile per data di iscrizione, filtrabile per attività
(attivi o meno), e cercabile per nome, cognome, codice fiscale o email.

## Ratificare l'Adesione

Un socio entra nel registro quando si iscrive, ma l'associazione decide
separatamente quando l'adesione è formalmente ratificata (ad esempio in
assemblea). L'azione **Ratifica adesione**, selezionabili una o più voci
dall'elenco, registra quella data in blocco.

## Importare ed Esportare

Il pulsante **Importare** carica un file CSV o XLSX di soci — utile per
portare dentro OpenSeat uno storico tenuto altrove. In caso di codice fiscale
già presente, si sceglie se sovrascrivere il socio esistente o aggiungerne
comunque uno nuovo.

L'azione **Esporta** sui soci selezionati genera lo stesso formato in uscita,
pronto per il commercialista o per il bilancio annuale.
