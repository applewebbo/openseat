# Applications

Every form filled in — completed or still a draft — is an **application**
(`Submission`), shown in **Admin → Association and applications →
Applications**. It is the only place to read the full detail of what
someone answered, including answers to any custom questions.

![The applications list](../assets/screenshots/admin-submissions-list.png)

## What Shows in the List

- The name of whoever joined (or the minor's, if it is for them)
- Which form it belongs to
- State: **draft** or **submitted**
- Whether publishing images is actually active — this accounts for the
  second consent too, when one is needed, not just the first answer
- When it was submitted

The list can be filtered by state, form and application type (for oneself,
for a minor, for someone under guardianship), and searched by name or
email.

## Signatures

Every submitted application carries its own **subscriptions**: who signed
what, when, and from which IP address. For an application involving a minor
with two holders of parental responsibility, this is also where the second
parent's consent state shows — pending, signed, or declined.
