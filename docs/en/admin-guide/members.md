# Member Register

Every application that is signed and confirmed becomes an entry on the
**member register**, in **Admin → Member register → Members**.

![The members list](../assets/screenshots/admin-members-list.png)

## Finding a Member

The list can be sorted by join date, filtered by activity (active or not),
and searched by first name, last name, tax code or email.

## Ratifying Membership

A member enters the register upon joining, but the association decides
separately when the membership is formally ratified (for example at an
assembly). The **Ratify membership** action, applied to one or more
selected rows, records that date in bulk.

## Importing and Exporting

The **Import** button uploads a CSV or XLSX file of members — useful for
bringing in a history kept elsewhere. If a tax code already exists, the
choice is whether to overwrite the existing member or add a new one
regardless.

The **Export** action on selected members produces the same format on the
way out, ready for the accountant or the annual report.
