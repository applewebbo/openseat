# Association

OpenSeat runs one association per installation: all of its settings live on
a single page, **Admin → Association and applications → Association**,
grouped by topic.

![The association's change page](../assets/screenshots/admin-association.png)

## Home Page

The first four fields — **logo**, **name**, **title** and **description** of
the home page — are what anyone sees first when landing on the site, in the
order they appear.

## Registered Details

Street, postcode, city, tax code and contact email: shown in the footer of
every public page and on the info page, if published.

## Statute and Fee

The link to the statute (or the uploaded PDF — if both are set, the PDF is
shown), and the annual membership fee, quoted on the application form.

## Info Page

A switch to publish it or not, and a free-form rich text that adds to the
contact details already shown automatically.

## Social Links

Website, Facebook and Instagram: when filled in, they appear as icons in
the footer.

## Bookings

When an event's bookings close automatically (at midnight before, at the
start time, or never — only manually at check-in), and the location
preselected for new events.

## Colours

The three colours — primary, accent and neutral — used across every public
page and in admin itself, which adapts its own palette to the association's.
A six-digit hex value is all each one needs.
