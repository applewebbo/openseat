# Check-in on the Day of the Event

On the day of the event, an editor (anyone with permission to change the
event) opens the event's public page and clicks **Manage event**: the same
page becomes the check-in desk, with no need to go through admin.

![The event management page, with the list of bookings](../assets/screenshots/event-checkin.png)

## Opening Check-in

Until check-in opens, bookings stay only announced. Opening it
automatically closes public bookings for that event — from that moment,
places are managed only from here.

## Confirming an Arrival

Each row in the list is an active booking; confirming it records that the
person actually showed up, along with how the fee was paid if one applies
(cash, bank transfer, other). A confirmation can always be undone, if
recorded by mistake.

## Adding Someone at the Last Minute

Anyone showing up without a booking can be added on the spot: searching by
their tax code auto-fills their details if they are already a member,
otherwise the minimum details needed are registered right there.

## Exporting the Members Acquired

Once the event is over, a dedicated action exports the members acquired
through it as a CSV — useful for whoever handles the accounts or writes the
initiative's report. This action needs a broader permission than check-in
itself requires: see [Users and Permissions](users.md).

## Closing Check-in

Closing check-in reopens public bookings, if the date still allows it —
useful if check-in was opened by mistake or too early.
