# Welcome to OpenSeat

**OpenSeat** is a free and open source, self-hosted booking manager for non-profit
associations. It takes membership applications, keeps the register with CSV
export, manages event bookings, and mails the booking list before each event —
one container, one database, no SaaS subscription, no member data leaving the
organisation.

## What does OpenSeat do?

- **Public home page** — the association's logo, name and description, written
  in the admin, above the next event date and the other open ones.
- **Public intake form** — a public link anyone can open, one section per step,
  covering parental-responsibility and image-consent rules. Drafts survive a
  lost connection and expire after thirty days.
- **Membership register** — every submitted application becomes an entry, with
  CSV export for the accountant or the annual filing.
- **Event bookings** — a member books a place for themselves and their family;
  someone new can join and book in the same flow. An event can also be set up
  as a pure booking that never touches the membership register.
- **The list, before the event** — at midnight before an event the booking list
  is mailed to the association automatically.
