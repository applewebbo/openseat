# The Second Parent's Consent

When joining on behalf of a minor and whoever signs is not the sole holder
of parental responsibility, publishing the child's images needs both
holders' consent. In that case the other parent receives an email with a
personal link.

![The consent page for the second parent](../assets/screenshots/second-parent.png)

The page summarises what the signatory answered — for the website and
social channels, and for the WhatsApp broadcast list — and leaves only two
choices:

- **I give my consent too** — from that moment the images may be published
  according to what was answered
- **I do not consent** — no image is published, but the membership stays
  valid: refusing changes nothing about the application

The link accepts only one answer: once chosen, the page shows only the
outcome and the date, with no way to change it from there — doing so
requires contacting the association directly.
