# Booking an Event

Every published event has its own page, with date, location, description,
and a way to book a place.

![An event page with open bookings](../assets/screenshots/event-landing.png)

## If You Are Not a Member Yet

The **Book** button opens the application form: by statute, attending an
event requires joining, so booking and applying happen in the same path
described in [Applying for Membership](join.md). The place is confirmed once
the application is signed.

![The first step of the form, opened from an event](../assets/screenshots/event-join-wizard.png)

!!! note "An event does not always require membership"
    An organiser can set an event as a plain booking: the form to fill in is
    the same, but completing it never creates or updates a member register
    entry. From the attendee's side, nothing about the path changes.

## If You Are Already a Member

Anyone with an active membership does not need to fill in the form again:
on the event page, below the main button, a link "Already been to one of
our events?" opens a small form asking for **email** and **tax code**.

![The recognition form for already-registered members](../assets/screenshots/event-identify.png)

If the details match a household already in the register, a list opens with
everyone in that household: just tick who is attending.

![Choosing who is attending, for an already-recognised member](../assets/screenshots/event-book.png)

Once confirmed, a confirmation email is sent for the first booking made for
that event.

![The booking confirmation](../assets/screenshots/event-booked.png)
